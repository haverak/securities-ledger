\# Securities Ledger



Учебное клиент-серверное приложение для учёта сделок с ценными бумагами.



\*\*Дисциплина:\*\* Разработка кроссплатформенных мобильных приложений  

\*\*Вариант:\*\* №6  

\*\*Стек:\*\* Flutter, Dart, Python, FastAPI, SQLAlchemy, SQLite.



\## Возможности



\- Создание, просмотр, редактирование и удаление сделок.

\- Справочники типов сделок, торговых площадок и валют.

\- Контроль связей между сделками и справочниками.

\- Поиск сделок по названию ценной бумаги.

\- Фильтрация по типу, площадке, валюте и диапазону дат.

\- Проверка вводимых данных.

\- Тёмная тема интерфейса.



\## Структура проекта



`mobile/` — Flutter-клиент.



`backend/` — FastAPI, модели базы данных и серверные маршруты.



\## Запуск сервера



Требуется Python 3.12.



Открыть терминал в папке `backend` и выполнить:



```powershell

python -m venv .venv

.\\.venv\\Scripts\\python.exe -m pip install fastapi "uvicorn\[standard]" sqlalchemy

.\\.venv\\Scripts\\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000

```



Документация API: `http://127.0.0.1:8000/docs`.



При первом запуске автоматически создаются пустые таблицы SQLite. Перед созданием сделок необходимо заполнить справочники типов, площадок и валют.



\## Запуск мобильного клиента



Требуются Flutter SDK и Android Studio с настроенным Android SDK.



Открыть `mobile` как Flutter-проект в Android Studio, выбрать Android Emulator и запустить `lib/main.dart`.



Для стандартного Android Emulator адрес API установлен как `http://10.0.2.2:8000`.



Сервер FastAPI должен работать на том же компьютере. На физическом Android-телефоне этот адрес не работает — потребуется другая конфигурация подключения.



\## Ограничения



Приложение является учебным проектом. Оно не подключается к биржам и не совершает реальные операции с ценными бумагами.



Локальное HTTP-соединение предназначено для разработки. Для публичного развёртывания необходимы HTTPS, аутентификация, авторизация и дополнительная защита сервера.
